# Üçüncü taraf paket değerlendirmesi

**Kaynak:** https://github.com/oknkeles/neostarsoccer-site

Depo README dosyası yayınlanmış oyun derlemesini barındırdığını belirtiyor. React ve ekranlara ait minify edilmiş JS/CSS modülleri bulunuyor; kaynak modüller, build konfigürasyonu ve resmi LICENSE yer almıyor. Site kullanım koşulları oyunun yazılımı ve tasarım haklarının Neo Star Soccer'a ait olduğunu söylüyor.

Yıldız Yolu, Neo Star Soccer markası, içerik metinleri, karakter varlıkları, stadyum modelleri ve JavaScript/CSS kodlarını içermiyor. Referans yalnızca genel etkileşim türleri (kayıt yuvası, çok adımlı karakter oluşturma, radar, pas hedefi, şut biçimleri) için kullanıldı ve bunlar bağımsız kodlandı.

**Önemli:** `neostarsoccer-site-main.zip` kullanıcının GitHub deposuna eklediği üçüncü taraf derlemeyi içeriyor. Hak sahibi izni yoksa bu ZIP'in kamuya açık repoda yayımlanması lisans/telif sorunu yaratabilir. Dosyayı bu turda silmedik veya çalışan oyuna dahil etmedik; kullanıcının silme ya da izin alma kararı gereklidir.
